# Install SCopy on a Steam Deck or Steam Machine

SCopy is a [Decky Loader](https://decky.xyz) plugin. Install Decky Loader first if you haven't already.

## From the URL (easiest)

1. In Decky's settings, turn on **Developer mode**.
2. Open **Developer**, choose **Install plugin from URL** and paste this address:

```text
https://github.com/MWGIH/SCopy/releases/download/decky-latest/SCopy.zip
```

To update, install from the same URL again.

## If the URL doesn't work, use the zip instead

1. Download **SCopy.zip** from this release (under **Assets**) in the Deck's browser (Desktop Mode), or copy it to the Deck's Downloads folder.
2. In Decky's **Developer** settings, choose **Install plugin from ZIP** and pick `SCopy.zip`. Don't unzip it first.

## Use it

Press the **...** (Quick Access) button, open the Decky plug icon and pick **SCopy**. Press **Start sharing**, then open the address it shows in a browser on your PC or phone and enter the PIN.
